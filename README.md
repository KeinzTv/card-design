# 🧊 Glassmorphism Landing Page

A sleek and minimal single page website featuring modern **glassmorphism** UI design with a 3D effect.

## 🚀 Demo

👉 [Live Demo](https://wr7yjq.csb.app/)

👉 [SandBox](https://codesandbox.io/p/sandbox/card-design-wr7yjq)

## ✨ Features

- Beautiful glassmorphism effects
- 3D effect
- Fully responsive layout
- Lightweight and fast
- Built with semantic HTML5, CSS and JS
- Easy to customize
- Custom cursor
